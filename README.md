## Purpose
The Mercury macropad is a 16+1 key macro pad aimed at being useful for a variety of purposes, the specifications of which is entirely up to the one who makes it. The design is centered around a nice!nano and nice!view, as well as Hotswap Kalih MX sockets.

You can either use the ([.STL](hardware/MercuryCase.stl)) or the ([View-Only Onshape Link](https://cad.onshape.com/documents/36be8d2820c932561b6e754c/w/a382f2a567d932feba75c19c/e/c855985b69218710006a8b27?renderMode=0&uiState=6aff60ae90390abc054af3d9)) to view the design.
